This folder is a placeholder.

TradingView's Advanced Charts library is not redistributable and is
therefore not committed to this repo. To make the Chart page work:

1. Get access to https://github.com/tradingview/charting_library
2. Copy the `charting_library/` folder from that repo into this directory
   (so `frontend/public/charting_library/charting_library.standalone.js`
   exists), and copy its `datafeeds/` folder into `frontend/public/datafeeds/`
   the same way.
3. Hard-refresh the browser.
